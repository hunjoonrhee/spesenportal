## GitHub

- PR을 열면 경로에 따라 Sabine(frontend) 또는 Markus(backend)가 자동 리뷰한다.
- PR 코멘트에 `@jonas`라고 쓰면 Jonas가 힌트를 준다.
- `[BE]`로 시작하는 PR은 BE 팀 것이고, 네가 리뷰한다. Tim의 PR에는 가끔 의도된 실수가 숨어 있다.

## 규칙 요약

- 팀은 네 티켓을 절대 대신 구현하지 않는다. 힌트만 준다.
- `.claude/team-notes/tech-debt.md`는 봉인 파일이다. 직접 찾아보는 게 공부지만, 열어봐도 된다.
- 회사 업무 관련 내용은 이 레포에 절대 넣지 않는다.
