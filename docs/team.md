## GitHub

- PR을 열 때 경로에 따라 Sabine(frontend) 또는 Markus(backend)가 자동 리뷰한다. push할 때마다 다시 리뷰하지는 않는다. 다시 리뷰받으려면 PR에 `re-review` 라벨을 붙인다(리뷰가 끝나면 라벨은 자동으로 떨어진다). push 뒤 1~2분 기다렸다가 붙이는 게 안전하다.
- 리뷰 스레드는 고친 사람이 "어느 커밋에서 어떻게 고쳤는지" 답글을 달고 직접 리졸브한다. 동의하지 않거나 범위 밖으로 뺀 항목은 답글만 달고 열어 둔다.
- PR 코멘트에 `@jonas`라고 쓰면 Jonas가 힌트를 준다.
- `[BE]`로 시작하는 PR은 BE 팀 것이고, 네가 리뷰한다. Tim의 PR에는 가끔 의도된 실수가 숨어 있다.
