# Willkommen im Team Spesenportal

Schön, dass du da bist! Diese Seite bringt dich in deiner ersten Woche auf den Stand.

## Das Produkt
Das Spesenportal ersetzt bei der Nordwerk AG die Excel-Vorlage für Reisekosten und Spesen. Mitarbeitende erfassen Ausgaben, Kostenstellenverantwortliche genehmigen sie, die Buchhaltung zahlt aus.

Stand nach Sprint 7: Erfassen, Einreichen und Ansehen funktionieren. Genehmigen gibt es nur als API. Ablehnen, Filter, Dashboard und Belege fehlen noch.

## Deine Rolle
Du bist Fullstack-Entwickler mit Schwerpunkt Frontend (etwa 70 % Frontend, 30 % Backend) und übernimmst die Stelle, die bisher unser Junior-Entwickler hatte.

## Dein erster Tag
1. `nvm install` im Projektordner (nutzt `.nvmrc`, Node 24)
2. `npm install` im Hauptordner (installiert Frontend und Backend mit)
3. `npm test` – alles sollte grün sein
4. `npm run dev` und http://localhost:4200 öffnen, als Anna Becker anmelden, eine Ausgabe erfassen
5. http://localhost:3000/api/docs ansehen
6. `docs/architecture.md` und die ADRs in `docs/adr/` lesen
7. Dein erstes Ticket ist ein kleiner Bug (EXP-61). Ideal, um den Ablauf von Branch bis Merge einmal durchzugehen.
